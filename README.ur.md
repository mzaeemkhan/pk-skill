# pk-skill

پاکستانیوں کے لیے اسکلز کا مجموعہ — اپنے AI ایجنٹ کو پاکستانی بنائیں

روزمرہ پاکستانی زندگی کے لیے Claude Code اسکلز کا مجموعہ۔ ٹرین کے اوقات، بس کے ٹکٹ، فلائٹس، بجلی کے بل، موسم، نماز کے اوقات اور بہت کچھ — روزمرہ کے چھوٹے موٹے کام اپنے AI ایجنٹ کے حوالے کریں۔

یہ Claude Code، Codex، OpenCode اور دوسرے کوڈنگ ایجنٹس کے ساتھ کام کرتا ہے۔

## انسٹالیشن

</div>

```bash
# تمام اسکلز انسٹال کریں
npx --yes skills add mzaeemkhan/pk-skill --all -g

# صرف ایک اسکل انسٹال کریں
npx --yes skills add mzaeemkhan/pk-skill --skill pakistan-railways -g
```

<div dir="rtl">

اس کے لیے Node.js 18 یا اس سے نیا ورژن اور npx ضروری ہے۔
